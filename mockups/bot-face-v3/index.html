How it works (all three): the eyes and mouth are no longer lit grid nodes. One parametric face (two mirrored eyes, a mouth; signed distance fields in the face grid's own coordinates) is drawn on a patch that sits on the head's front surface, so it turns, tilts, nods and shakes with the head. Every expression is a parameter set and morphs into the next; blink, glance and the voice's visemes (open / ee / oo) act on the parameters. The grid nodes under a feature are hidden. Options differ only in parameters and in how the shapes are drawn (anti-aliased vs a snapped dot grid). The Settings thumbnails and the 2D fallback draw the same shapes as vector paths through the same projection.
Recommendation: A · Smooth glyphs. It fixes exactly what the user saw (blocky eyes with holes, a broken mouth) at every size, keeps the wireframe head and the glow, and is the most expressive of the three: lids for thinking, a catchlight when it needs you, happy arcs, an x, a mouth that really opens with the voice. B is the right pick only if the LED character is part of the brand (it is clean now, but at the dock size a 2 x 2 dot eye says less than a glyph). C is the calmest on a desktop but loses expression below ~50 px and when the colour preset is "mint" or "mono" (the states differ mostly by colour). Cost: on the GPU path +0.1-0.2 ms JS per frame; the face patch is one extra small draw per head. Under SwiftShader (CPU rasteriser) the per-pixel shapes cost a vsync step (30 -> 20 fps in the 7-head 1080p bench); on a real GPU that is a few thousand fragments. The 2D fallback is as cheap as before.

A · Smooth glyphs

Rounded-rectangle eyes and a smooth arc mouth, anti-aliased vector shapes drawn on the head's front surface (they turn and tilt with it), a soft glow. Expressions morph (eyes squash to lids, arcs, an x); the mouth is a rounded D that opens with the voice (open / ee / oo). Reads at every size; the most 'product' look.

B · Refined dot matrix

The LED look kept, done properly: the same shapes sampled on a symmetric dot grid whose pitch is picked per device size (40 / 30 / 22 / 16 / 12 dots across), every shape snapped to whole dots, curves one dot per column. Solid eyes, no holes, symmetric at every size; the smallest sizes get their own coarse set (2 x 2 eyes, flat mouth).
